# Guardrails

## Audience and positioning

- Ember is for PhDs and early-career professionals in ANY field, including the sciences. It is never a general-purpose CRM for all professionals.

- Ember is always positioned as a general academic career tool. It is never positioned as a healthcare, pharma, biomedical or life-sciences product.

## Example contacts, demo data and copy

- Allowed fields: physics, chemistry, materials science, earth and environmental science, ecology and evolution, plant biology, astronomy, math, computer science, engineering, social sciences, humanities.

- Do NOT use: medicine, clinical research, biotech, public health, hospitals, or pharma or biotech companies.

- Never use the words: KOL, key opinion leader, HCP, pharma, medical, clinical, patient, MSL, medical affairs.

- Never describe Ember as an "expert network" or a tool for tracking or engaging experts.

## Safety and code

- Never commit secrets. API keys only in .env.local or host environment settings.

- Explain changes in plain English; the founder is non-technical.

- Before finishing any task, run the tests and report results.
